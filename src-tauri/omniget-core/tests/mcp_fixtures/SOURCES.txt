Recorded MCP servers (plan §3, Fase 3, "Plano B": real servers diverge from the
spec, so the divergence lives in the test suite instead of in a bug report).

How: each file is one real stdio session driven by a recorder that sends
`initialize`, the `notifications/initialized` notification, `tools/list` and one
`tools/call`, and writes down what came back. Recorded 2026-09-18 on macOS 15
(darwin 25.5.0), node v22.22.3, npx 10.9.8. Nothing is hand-written; nothing is
synthetic.

Post-processing, by scripts/../scratchpad sanitizer (same for every file):
- the recorder's sandbox path and the user's home directory were replaced by
  /tmp/mcp-sandbox and /Users/user;
- any string longer than 1500 characters was cut, with a marker at the end;
- no credential was used to record any of these, and a test
  (`no_recorded_fixture_contains_a_token`) fails the build if one appears.
